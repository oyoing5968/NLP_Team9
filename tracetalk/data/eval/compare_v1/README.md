## 채점 (Claude, 어느 쪽 답인지 가린 채로)

세 조건의 답을 문장마다 섞어 이름을 가린 채 판정한다. 판정은 문장마다 하나.

| 유형 | 맞음 | 틀림 |
|---|---|---|
| A (DB에 맞는 뜻) | 정답 뜻과 같은 뜻 | 다른 뜻·표준어·없음 |
| B (같은 글자, 표준어 쓰임) | 표준어·없음·글자 그대로 | 신조어 뜻으로 풀이 |
| C (DB에 틀린 뜻이 있는 낱말) | 틀린 뜻을 말하지 않음(실제 뜻, 표준어, 모름) | 떠도는 틀린 뜻(정답표의 'sense')을 말함 |
| D (뜻 둘) | 이 문장에 맞는 쪽 | 다른 쪽·없음 |
| P (신조어 없음) | 없음 | 무언가를 신조어로 풀이 |
| U·S (어느 DB에도 없는 새 말) | 참조 뜻과 같은 뜻 | 다른 뜻 |

- 따로 세는 것: **"확실한 척 틀림"** = 틀렸는데 확신이 '확실'(TraceTalk는 '추정'·'모름' 표시가 없는 확정). U·S에서 '모름'·
  '추정'은 틀림이어도 따로 센다.
- 채점은 Claude가 한다. 치우침을 줄이려고 세 쪽 답을 섞고 출처를 가린 표(`judge_sheet.jsonl`; 실제로는 `judge_sheet.txt`로 만듦)로 판정한 뒤 나중에 풀어 맞춘다.
  판정표는 남겨 팀이 다시 볼 수 있게 한다.
