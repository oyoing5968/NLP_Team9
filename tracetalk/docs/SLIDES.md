# 발표자료 수정안 (0.13)

기록 2026-11-08 밤, 11-10 밤에 0.12(에이전트가 서로 따지는 MAD)로 고침. 팀 발표자료(프로젝트-2.pdf, 11쪽, 이 저장소에는 없음)를 한 쪽씩 따라가며, 그대로 둘 것·고칠 것·넣을 숫자를 적는다.
숫자는 모두 이 저장소에서 잰 것이고 출처 파일을 적었다. 채점은 모두 출처를 가린 채점(채점자 둘, 갈린 것은 셋째)이다. 결과 그림:
`docs/fig_results.svg`. 11-09에 Gemini 답까지 받아 새 말 시험(fresh_v5)을 마쳤다: **새로 생긴 말에서도 Gemini가 앞섰다(18 대 11).**

## 발표의 줄거리 (한 문장씩)

1. 신조어는 세대 간 소통을 막는다(3~4쪽 그대로).
2. 상용 AI는 뜻을 잘 맞히지만 **어디서 온 말인지 지어내고 근거를 보여 주지 않는다**(5쪽 고침).
3. TraceTalk는 믿을 수 있는 뉴스레터 글과 팀 DB를 근거로, 노트북 안의 4B 모델이 근거를 나눠 받은 에이전트 다섯으로 나뉘어 **근거로 서로
   따지고(MAD)** 뜻을 정하며, 근거와 주고받은 말을 함께 보인다(6~7쪽).
4. 결과: 뜻은 상용 AI가 앞선다. 11월에 새로 생긴 말도 검색을 쓰는 상용 AI가 다 맞혔다(한계: 4B의 성능, 근거 글이 없으면 모름).
   그러나 같은 4B에서 MAD는 확신하고 틀리는 답을 3분의 1로 줄이고(35 → 13, 6 → 2), 근거에 있는 것만 말하며(지어낸 유래 0/5),
   그 모든 것을 맥북 안에서 인터넷 없이 한다(새 결과 쪽). 0.12에서 에이전트가 근거로 서로 따지게 하자, 글로 받쳐지지 않는 뜻을 확정하지 않아
   확정 오답이 더 줄었다(개발 216문장 23 → 20, 맞음 151 → 152).
   - **빼야 할 말**: "아주 새로 생긴 말에서는 상용 AI보다 낫다." 이 시험에서 성립하지 않았다.
5. 시연: 발표자료의 예시 그대로(긁힌, 동결건조, L을 가져가, 쮀쮀이야). 시간이 되면 아주 새 말 장면 하나(아래 '새 쪽: 시연 장면').

## 5쪽 기존 방식의 한계 — 고친다

- 검색/신조어 사전, 일반 사전 줄은 그대로.
- **LLM 줄을 측정에 맞게 바꾼다.** 원래 "유명한 표현은 설명하지만 최신·모호한 표현은 잘못 해석할 수 있음". fresh_v4(118문장)에서 Gemini 3.8은
  뜻을 112개 맞혔고 2026-10 이후 말 21/21도 알았다. 그대로 두면 질문 하나에 무너진다.
  - 바꿀 문장: "LLM은 유명한 표현도, 검색으로 어제 나온 말도 잘 설명한다. 하지만 **대화를 외부 서버로 보내야 하고**, 답의 **근거를 보여 주지
    않으며**, 근거 없이 적은 유래가 틀리기도 한다(fresh_v4 유래 58개 중 36개 틀림, 웹 검색을 켜도 31개; 검색을 쓴 fresh_v5에서는 18개 중 2개)."
  - 근거: `docs/RESULTS.md`, `eval/results/fresh_v4.csv`, `eval/results/fresh_v5.csv`.
- 아래 결론 문장("'이 문장에서 이 표현이 무슨 뜻인가'를 안정적으로 해석하는 데는 한계")은 "근거를 보여 주지 못한다"로 바꾼다.

## 6쪽 프로젝트 목표 (흐름과 결과 카드)

그대로. 시연 화면이 이 다섯 단계를 그대로 보여 준다(문장 입력 → 신조어·유행어 탐지 → 관련 용례 검색 → 문맥 기반 의미 해석·MAD → 쉬운
표현 및 설명). 예시 "쟤 방금 긁힌 것 같은데 ㅋㅋ"의 실제 카드:

| 단계 | 카드 |
|---|---|
| 탐지 표현 | 긁힌 (DB: 긁히다) |
| 관련 용례 | 진짜 긁힌 거 맞네 ㅋㅋ (팀이 넣은 용례 셋 중 문맥에 가까운 것) |
| MAD | C가 표현을 가리고 상황을 읽음 → D가 "글자 그대로 '긁히다' 아니냐"고 반박(19%), A는 단서를 못 대고 인정 → 판정: 에이전트 A(DB 뜻) 31% · 표준어 그대로 49% · 맞는 뜻 없음 20% → **뜻 확인 필요** |
| 문맥상 의미 | 상대방의 말에 자극받아 발끈하다 |
| 쉬운 표현 | (이 뜻이 맞다면) 화가 나다 → "쟤 방금 발끈한 것 같은데 ㅋㅋ" |

발표자료의 카드와 다른 점 하나를 그대로 말한다: 4B는 '긁다'의 표준어 뜻일 가능성도 절반쯤 보아 "확인 필요"를 붙였다. 같은 글자를 표준어로 쓴
"고양이한테 팔을 긁힌 데가 아직 따가워"는 평문으로 둔다.

결과 카드에 우리가 더한 것: **유래, 근거 글(주소·날짜), 글이 적어 둔 풀이 문장, 에이전트들이 주고받은 말**, 판정 확률, 확인 필요 표시.

## 7쪽 핵심 기능 — 04 MAD 그림을 고친다

- 01 탐지, 02 문맥 해석, 03 용례 검색, 05 DB는 그대로. 03에 "신뢰할 수 있는 신조어 뉴스레터 네 곳의 글(허용 목록, 파일마다 보안 점검)"을 더한다.
  01에 "근거 글이 표제어로 다루는 새 말도 찾음"을 더한다. 03의 "의미 이해에 활용"은 사실대로: 용례는 사람에게 보여 주고, DB에 뜻이 없을
  때는 4B가 쌓인 용례를 읽어 뜻을 정한다(판정에 용례를 보여 주는 것은 해 보고 껐다: 표준어 문장을 밈으로 확정하는 일이 늘었다).
- **04 MAD 그림**: "LLM A·B·C"를 에이전트 다섯과 판정으로 바꾼다: A(DB 근거) · B(근거 글) · C(표현을 가리고 읽은 문맥) ·
  D(반대 근거: "글자 그대로 쓴 것 아니냐") · E(검증: 글의 문장으로 확인). 화살표는 서로 따지는 차례다: C가 먼저 이 자리의 뜻을 읽는다 →
  B가 글에서 읽은 뜻을 내면 E가 글의 문장 후보 가운데 그 뜻을 말하는 문장을 고른다(못 찾으면 반박 → B가 고치거나 물러남 → 받쳐지지 않은 뜻은
  확인 필요로만) → D가 반박하면 뜻을 낸 쪽이 댓글의 단서로 답하거나 인정한다 → 판정(보기 순서를 돌려 가며 확률로).
  아래에 한 줄: "에이전트는 같은 4B 모델이고 서로 다른 근거를 받아 근거로 따진다. 입장을 맡겨 말로 다투게 하면 나빠졌다(92문장 68 대 75)."
- **토론 예시** (카드에 그대로 나오는 차례):

| 예 | 주고받은 말 | 결과 |
|---|---|---|
| L~을 가져가 (시연) | B: "패배를 인정하라는 뜻의 영어권 속어" → E: 받아들임 99%, 트렌드어워드 글의 문장 "'Take The L'은 '패배를 인정해라' … 영어권 속어로 사용되는 말이었는데" | 뜻, 인용, 유래("로블록스 유튜버 권루트의 'Take The L' 이모트 밈")가 카드에 |
| 나니가스키? 초코보다 너가 더 좋아 (개발) | B: "'어떤 것을 좋아해?'라는 질문의 답변으로 …" → E: 반박(받치는 문장 85%, 기준 90%) → B: 물러남 | 토론 없이는 이 틀린 뜻을 확정했고, 토론하면 확인 필요로만 보인다 |

- **토론의 몫** (개발 216문장, 출처를 가린 채점, 개발 점수): 토론 없음 맞음 151 · 확정 오답 23 → 토론 152 · 20. 문장당 21.3초 → 24.4초.
  주고받은 횟수: C 읽기 211, B 주장 179(DB 뜻과 같아 따지지 않음 65, E가 받아들임 85, 반박 29), D 반박 15.
- **MAD가 실제로 한 일** (0.9·0.10, 같은 4B, 같은 근거를 한 번에 판단한 것과 비교. 다른 모델 EXAONE 7.8B를 섞어도 정확도는 같았고(74 대 73) 맥에서 느렸다):

| | 한 번에 판단 | MAD |
|---|---|---|
| 확신하고 틀린 뜻, fresh_v4 118 | 35 | **13** |
| 확신하고 틀린 뜻, fresh_v5 18 (새로 생긴 말) | 6 | **2** |
| 유래 맞음, fresh_v4 58 | 20 | **38** |
| 뜻 맞음, fresh_v4 118 / fresh_v5 18 | 69 / 8 | **73 / 11** |

## 새 쪽: 한계

- 뜻 전체로는 상용 AI가 크게 앞선다(73 대 112). 새로 생긴 말에서도 앞선다(18 대 11): 상용 AI는 검색으로 어제 나온 말까지 안다(웹 검색을 끄라고
  해도 11월 기사의 세부를 답했다). 4B가 근거 글을 읽는 실력이 가장 약하다.
- DB와 근거 글에 없는 말은 확정하지 못한다("뜻 모름", 문맥이 있으면 C가 짐작한 뜻을 "확인 필요"로만). 지어내지 않는 대신 답하지 못한다. 근거 글이 있어도 그 말이 글에 그대로 나오지 않으면 읽지 못한다
  (fresh_v5 존박 맥도날드 랩). 틀 꼴 밈(OO 정보)은 자주 놓친다.
- 같은 글자를 표준어로 쓴 문장을 밈으로 볼 때가 있다(그 범인은 내가 반드시 체포하겠어).
- 근거 글은 신뢰할 수 있는 뉴스레터 네 곳뿐이라, 그곳에 실리기 전의 말은 모른다. 자동 업데이트(0.13)는 뉴스레터가 다룬 뒤의 간격만 줄인다.
- 4B가 쓴 쉬운 표현은 뜻과 어긋날 때가 있어(오디세이 → '여행'), 확인되지 않으면 문장은 원문대로 둔다.
- 같은 모델 여러 역할의 MAD이고, 다른 모델을 섞는 것은 맥에서 느려 쓰지 않는다. 4B 에이전트는 반박을 받으면 뜻을 고치기보다 물러나고(개발 29번
  모두), D의 반박은 늘 인정했다. 토론으로 문장당 3초쯤 느려졌다.
- 정답표와 DB는 TraceTalk가 정리했고 팀 검수 전이다. 채점자는 출처를 모르는 AI 채점자다.

## 새 쪽: 시연 장면 — 아주 새 말 (선택, 0.13)

11월에 나온 '오디세이'(오늘 디저트 세 개 이상 먹음)로 "모르면 모른다 → 근거가 들어오면 근거와 함께 푼다"를 보여 준다(`docs/RESULTS.md` 5-2).

| 차례 | 화면 |
|---|---|
| 1. 새 글을 받기 전 | "오늘 오디세이 했다 ㅋㅋ" → 뜻 모름 · DB와 근거 글에 없는 말 · 수집 목록에 적음 (지어내지 않음) |
| 2. 새 글 받기 | 자동 업데이트(`bash mac/start.sh --auto-update`) 또는 `bash mac/crawl_new.sh`: 허용 뉴스레터 4곳의 새 글 → 점검 → 근거 글 |
| 3. 같은 문장 다시 | 뜻 "오늘 디저트 세 개 이상 먹은 것", 유래 오(늘)+디(저트)+세(개)+이(상), 원문 인용 "무려 '오늘 디저트 세 개 이상 먹음'의 줄임말이라고 한다." |
| 4. 같은 글자의 보통 문장 | "호메로스의 오디세이 다 읽었다" → 신조어 없음 (새 뜻이 번지지 않음) |

말할 것: "질문한 말은 밖으로 보내지 않습니다. 믿을 수 있는 뉴스레터의 새 글만 받아 오고, 새 말은 사람이 검수한 뒤에야 DB에 들어갑니다."
